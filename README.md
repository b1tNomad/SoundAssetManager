# Easy Sound Manager

Локальна тулза для звуків до ігор. Працюєш на дошці, як у Figma чи Miro. Кожен звук — картка. Фрейми — це водночас папки й набори інструментів: нарізка, обрізка, склейка. Є ефекти, шов для лупів і експорт в ogg, mp3 або wav.

## Запуск

1. Один раз встанови ffmpeg (він робить усю обробку звуку):
   ```
   brew install ffmpeg
   ```
2. У папці проєкту запусти:
   ```
   npm start
   ```
   Браузер сам відкриє http://localhost:3737

`npm install` не потрібен. Інтерфейс уже зібраний, а сервер працює на чистому Node без залежностей. Потрібен Node 18 або новіший.
Якщо Homebrew немає, `npm install` завантажить запасний ffmpeg (ffmpeg-static). З brew-версією якість ogg краща.

Зупинити застосунок: `Ctrl+C` у терміналі.

## Як цим користуватись

**Дошка (посередині)**
- Кожен звук — картка з хвилею. Нарізані шматки, склейки й інші результати теж стають картками, і з ними можна робити все те саме.
- Рух дошки: два пальці на трекпаді, колесо миші, середня кнопка або «Рука» (`H`).
- Масштаб: щипок, `⌘` + колесо, `⌘+` / `⌘−`. `⇧1` показує все, `⇧2` — вибране.
- Картку перетягуєш за шапку (там, де назва). З `Alt` перетягнеш копію.
- Ширина картки змінюється за правий край вибраної картки.
- Рамка по порожньому місцю виділяє кілька карток. `Shift` або `⌘`-клік додають до виділення. Стрілки посувають вибрані картки.
- Здалеку картки показуються спрощено (назва й хвиля), а наблизиш — повноцінно.
- Файли з Finder можна кидати просто на дошку: вони з'являться там, куди кинув.
- `⌘Z` / `⇧⌘Z` скасовують і повертають будь-які зміни на дошці.

**Фрейми**
- `F` або кнопка «Фрейм» унизу: обираєш тип і протягуєш на дошці. Картки, що опинилися всередині, входять у фрейм.
- Типи:
  - **Нарізка** — відрізки на хвилі, кожен стає окремим файлом;
  - **Обрізка** — залишити виділене, видалити виділене або лише фейди;
  - **Склейка** — склеює картки фрейму зліва направо й зверху вниз (номери на картках). Галочка на картці вмикає її у склейку чи вимикає;
  - **Вільний** — просто папка для звуків.
- Фрейм — це папка. Що збережеш усередині, лягає в `data/library/<назва фрейму>/` і з'являється картками в тому ж фреймі. Перейменуєш фрейм — перейменується й папка.
- Фрейм перетягуєш за назву над ним, розмір змінюєш за кутики. Подвійний клік по назві перейменовує.
- Кілька карток можна «Обгорнути у фрейм» (права панель). Якщо вони розкидані, то зберуться в нове місце.
- «Експорт фрейму» (права панель, коли вибрано фрейм) кладе всі його звуки в ogg, mp3 чи wav у папку, яку фрейм запам'ятовує (наприклад, папку звуків гри). Або скачує одним .zip.

**Дубль**
- `⌘D` або меню ⋯ на картці → «Дубль з усіма змінами»: копія з відрізками, виділенням, ефектами, лупом. Наприклад, щоб спробувати ті самі відрізки з іншими ефектами.
- «Чистий дубль» — той самий звук без жодних змін, щоб почати заново чи забекапити.
- Дубль не копіює файл на диску. Це ще одна картка того самого звуку.

**Шари (ліворуч)** — це бібліотека
- Дерево: фрейми поточної дошки з картками, далі «Поза фреймами».
- Клік показує картку на дошці, подвійний клік наближає до неї.
- «Без картки» — звуки, які є в бібліотеці, але не лежать на жодній дошці. Їх можна перетягнути на дошку або видалити файл.
- Пошук шукає по всіх дошках. Фільтри: «Імпортовані», «Створені», «Обрані».
- «Додати файли» кладе файли у вибраний фрейм або туди, куди зараз дивишся.

**Бічні панелі згортаються** у вузькі смужки з іконками. Ліву (шари) згортаєш і розгортаєш сам: кнопкою вгорі або `⌘\`. У згорнутій лишаються пошук, «Додати файли» й кнопки фреймів дошки для швидкого переходу. Права розгортається сама, коли щось виділено, і згортається, коли виділення немає. Її теж можна згорнути вручну, і вона розгорнеться знову при наступному виділенні. Іконки в згорнутій правій смужці відкривають потрібну вкладку.

**Права панель** показує інструменти виділеного
- Одна картка: вкладка за типом фрейму (Нарізка / Обрізка / Склейка), «Ефекти», «Шов».
- Фрейм: тип, папка, склейка (для фрейму склейки), експорт.
- Кілька карток: вирівняти рядком, стовпцем чи сіткою, обгорнути у фрейм, експорт, .zip.
- Нічого не вибрано: швидке створення фрейму й шпаргалка клавіш.

**Хвиля**
- Клік перемотує. Протягни мишкою, щоб виділити (в «Обрізці») чи додати відрізок (у «Нарізці»; з `Alt` — поверх наявних).
- `Alt` + колесо або `−`/`+` на вибраній картці наближають хвилю.
- «Луп» (або `L`) вмикає відтворення по колу, навіть під час відтворення.
- «Шов» допомагає з лупами:
  - кольорова смужка під хвилею показує, де кінець зійдеться з початком: зелене — чисто, жовте — майже, червоне — буде клацання або «пум»;
  - «Підібрати кінець/початок» сам знаходить найкращу точку.
- «Ефекти» змінюють звук картки, і він одразу так і грає (хвиля фіолетова).
  - Пресети: Космос, Робот, Прибулець, Рація, Телефон, Мегафон, Під водою, Печера, Собор, Кімната, Монстр, Велетень, Бурундук, Привид, 8-біт, Платівка, Лоу-фай, Дисторшн, Вобл, Сповільнення, Реверс.
  - Окремі ефекти:
    - тон, швидкість, темп, задом наперед;
    - робот / шепіт, зсув частот, кільцева модуляція, перегруз, біткрашер, шум і тріск;
    - еквалайзер, фільтри, автофільтр;
    - вібрато, хорус, флейнджер, фейзер, тремоло;
    - луна, реверберація, стерео, компресор, гучність.
  - Відрізки, обрізка, склейка, експорт і скачування цієї картки підуть з ефектами. «Зберегти з ефектами» робить новий звук з усього треку.

Кожна дія створює **нові** файли, оригінали не змінюються. Виділення й відрізки прослуховуються одразу із затуханням, так само, як збережуться.

**Гарячі клавіші**: `Пробіл` грати / стоп вибрану картку · `Enter` грати виділене · `L` луп · `S` розрізати в курсорі (нарізка) · `Delete` прибрати вибраний відрізок, а якщо його немає — картку з дошки (файл лишається) · `⌘D` дубль · `⌘Z` скасувати · `F` / `V` / `H` фрейм, вибір, рука · `⌘\` згорнути / розгорнути шари · `Esc` стоп і зняти виділення.

## Де лежать дані

- `data/library/` усі звуки; підпапки — це фрейми
- `data/db.json` бібліотека, дошки з фреймами й картками та налаштування (звичайний JSON, база даних не потрібна)
- `data/exports/` папка експорту за замовчуванням
- `data/tmp/` тимчасові файли. Кожна дія прибирає за собою, навіть якщо впала з помилкою. Решту чистить фонова прибиралка (усе старше години) і кожен новий запуск.

При першому запуску нової версії старі столи стають дошками: картки столу — у фреймі з назвою столу. Звуки, яких не було на столах, ідуть у фрейм «Бібліотека».

При запуску застосунок звіряє бібліотеку з диском. Записи, чиїх файлів уже немає, прибираються. Аудіофайли в `data/library/` (і її підпапках), яких немає в базі, додаються й з'являються в «Без картки».

Резервна копія: просто скопіюй папку `data/`.

## Розробка

```
npm install      # esbuild + react для збірки інтерфейсу
npm run dev      # перезбирає інтерфейс і перезапускає сервер при змінах
npm run build    # одноразова збірка в client/dist
```

- `server/` містить HTTP-сервер (без express), сховище в JSON, операції через ffmpeg (`ops.js`) і перенесення столів на дошки (`boards.js`)
- `client/src/` містить інтерфейс на React: дошка (`Canvas.jsx`), шари (`Layers.jsx`), права панель (`Inspector.jsx`), картка з хвилею (`TrackCard.jsx`, `Waveform.jsx`)
- `shared/fx.js` містить усі ефекти. Той самий код працює в браузері (у фоновому потоці, `fxWorker.js`) і на сервері під час збереження, тому файл звучить точно як прослуховування
- `shared/board.js` містить геометрію дошки: розміри карток, розкладку у фреймах, порядок склейки
